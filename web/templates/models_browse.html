What do the format badges mean?

Quantization does two different jobs, and treating them as one causes most of the disappointment. Making a model fit is about the size of the weights on disk and in VRAM. Making it fast is about what the matrix units execute. A format that only does the first will save you memory and run at the same speed, or slower.

FP1616-bitbf16/fp16 Unquantized. The reference for both quality and speed.
FP88-bitfp8, where the hardware has it Weights and activations. The one common format that can genuinely speed up compute — but only on parts with FP8 matrix units (RDNA4, Hopper/Ada/Blackwell, MI300+). On older parts it saves memory and computes at bf16.
AWQ, GPTQ4-bitbf16 Weight-only: the weights are dequantized back to bf16 before the matmul. Quarters weight memory on any card, speeds up compute on none. Pick these to fit, never to go faster.
MXFP4, NVFP44-bit block floatdepends Newer formats with real hardware support on some parts and an emulated path on others. Measure rather than assume.

If a model already fits, a 4-bit version of it will not be faster. It will usually be slightly slower, and slightly worse. Reach for 4-bit when the alternative is not running the model at all — and for FP8 when your GPU can execute it. The Help page has the same table with the RDNA4 specifics, and the Benchmarks page will tell you what any of this actually does on your hardware.
