Runtime environment

Environment variables applied to the vLLM process. They take effect the next time vLLM starts, so a running model keeps the environment it was launched with — restart it to pick these up.

These are applied after the container's own environment, so a value set here replaces what the image exports. The effective environment at the bottom shows what that works out to.
